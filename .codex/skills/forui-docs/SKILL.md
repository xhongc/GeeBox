Forui 提供符合 llms.txt 规范的机器可读文档接口。这些接口使 LLM 和 AI 工具能够轻松理解和使用 Forui。
`./references/llms.txt`这是一份简洁的文档页面索引，包含标题、描述和链接。您可以以此为起点，查找可用的文档。
`./references/llms-full.txt`完整的文档内容以纯 Markdown 格式呈现。这包括所有包含代码示例、API 详情和使用说明的页面。
